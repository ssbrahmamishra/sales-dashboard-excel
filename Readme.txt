# 📊 Sales Analysis Dashboard (Excel 2007)

## 🔍 Project Overview
This project analyzes sales data using **Microsoft Excel 2007** to identify key business insights such as top-performing products, regional sales distribution, and monthly sales trends.  
The analysis is built using **Pivot Tables, Pivot Charts, and Excel formulas**, without using any advanced Excel functions, ensuring full compatibility with Excel 2007.

---

## 📁 Dataset Description
The raw dataset contains **20 sales orders** with the following fields:

- Date  
- Order ID  
- Region  
- Salesperson  
- Product  
- Category  
- Quantity  
- Unit Price  
- Total Sales (Quantity × Unit Price)  
- Month  
- Year  

All data is clean, structured, and normalized for analysis.
